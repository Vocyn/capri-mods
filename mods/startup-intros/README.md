# Startup Intros

Three start-up animations: Hijack, Shatter and Wake. She shuffles them each time she starts, or you pick one.

- Kind: code mod
- Made by: Vocyn

Say "play intro" to watch one now, "intro shatter" (or hijack, or wake) to lock one in, and "shuffle intros" to go back to shuffling.

Code mods run C# on your PC, so she asks before turning one on. This one only draws on screen, plays her sounds and saves your pick in its own mod folder. Code mods are Windows only for now.
