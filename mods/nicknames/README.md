# Nicknames

Give Capri new names just by asking, out loud or in chat. She answers to them straight away and remembers them.

- Kind: code mod
- Made by: Vocyn

| Say or type | What happens |
| --- | --- |
| "Capri, answer to Kit" | She answers to Kit too |
| "Capri, call yourself Nova" / "your nickname is Big Z" / "I'll call you Sparky" / "add the name Pip" | Same, other ways to say it |
| "Capri, what are your names?" / "what can I call you?" | She lists them |
| "Capri, stop answering to Kit" / "forget the name Kit" | She drops that one |
| "Capri, forget all your names" | Back to just Capri |

Names can be up to three words, up to 20 of them. Ordinary talk like "I'll call you later" is left alone. The names are kept as My Nicknames on the Mods page, so you can turn them off there without losing them. Sharper Ears helps her catch unusual names.

Code mods run C# on your PC, so she asks before turning one on. This one only reads what you say to her and keeps a small names file in the mods folder. Code mods are Windows only for now.
